Exercice 1 Variables & Concaténation

Créez trois variables : firstName (chaîne de caractères), lastName (chaîne) et age (nombre). Assemblez-les avec + pour afficher une phrase complète avec console.log().

Exemple 1 :
Entrée : firstName = 'Alice', lastName = 'Smith', age = 25
Sortie : Bonjour, je m'appelle Alice Smith et j'ai 25 ans.

Exemple 2 :
Entrée : firstName = 'Omar', lastName = 'Benali', age = 30
Sortie : Bonjour, je m'appelle Omar Benali et j'ai 30 ans.
Voir la Solution 
function introduce(firstName, lastName, age) {
  return 'Bonjour, je m\'appelle ' + firstName + ' ' + lastName + ' et j\'ai ' + age + ' ans.';
}

console.log(introduce('Alice', 'Smith', 25));
console.log(introduce('Omar', 'Benali', 30));

Exercice 2 Pair ou Impair (if / else)

Écrivez une fonction nommée checkEvenOrOdd(number) qui retourne 'Pair' si le nombre est divisible par 2, et 'Impair' sinon. Testez-la avec 4 et 7.

Exemple 1 :
Entrée : checkEvenOrOdd(4)
Sortie : 'Pair'

Exemple 2 :
Entrée : checkEvenOrOdd(7)
Sortie : 'Impair'
Voir la Solution 
function checkEvenOrOdd(number) {
  if (number % 2 === 0) {
    return 'Pair';
  } else {
    return 'Impair';
  }
}

console.log(checkEvenOrOdd(4)); // 'Pair'
console.log(checkEvenOrOdd(7)); // 'Impair'

Exercice 3 Somme d’un Tableau (for...of)

À partir d’un tableau de prix, écrivez une boucle for...of pour calculer la somme totale et l’afficher.

const prices = [10, 25, 15, 50];
Exemple 1 :
Entrée : [10, 25, 15, 50]
Sortie : Total : 100

Exemple 2 :
Entrée : [5, 5, 10]
Sortie : Total : 20
Voir la Solution 
function sumPrices(prices) {
  let total = 0;
  for (const price of prices) {
    total = total + price;
  }
  return 'Total : ' + total;
}

console.log(sumPrices([10, 25, 15, 50]));
console.log(sumPrices([5, 5, 10]));

Exercice 4 Compter les Adultes (for...of + if)

Écrivez une fonction countAdults(ages) qui prend un tableau d’âges et retourne combien de personnes ont 18 ans ou plus (>= 18).

const ages = [12, 19, 25, 16, 30];
Exemple 1 :
Entrée : countAdults([12, 19, 25, 16, 30])
Sortie : 3

Exemple 2 :
Entrée : countAdults([10, 15, 17])
Sortie : 0
Voir la Solution 
function countAdults(list) {
  let count = 0;

  for (const age of list) {
    if (age >= 18) {
      count = count + 1;
    }
  }

  return count;
}

console.log(countAdults([12, 19, 25, 16, 30])); // 3
console.log(countAdults([10, 15, 17]));         // 0

Exercice 5 Trouver un Employé par Nom (Objets)

À partir d’un tableau d’objets employés, écrivez une fonction findEmployee(employees, targetName) qui retourne l’objet employé correspondant s’il existe, ou 'Non trouvé' sinon.

const employees = [
  { id: 1, name: 'Alice', role: 'Developer' },
  { id: 2, name: 'Bob',   role: 'Designer' },
  { id: 3, name: 'Sara',  role: 'Manager' }
];
Exemple 1 :
Entrée : findEmployee(employees, 'Bob')
Sortie : { id: 2, name: 'Bob', role: 'Designer' }

Exemple 2 :
Entrée : findEmployee(employees, 'Omar')
Sortie : 'Non trouvé'
Voir la Solution 
function findEmployee(employees, targetName) {
  for (const emp of employees) {
    if (emp.name === targetName) {
      return emp;
    }
  }
  return 'Non trouvé';
}

console.log(findEmployee([
  { id: 1, name: 'Alice', role: 'Developer' },
  { id: 2, name: 'Bob',   role: 'Designer' }
], 'Bob'));
