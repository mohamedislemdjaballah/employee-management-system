Launch Guide — PostgreSQL & Demo Apps

How to start PostgreSQL, create demo_db in pgAdmin, and run both demo-decoupled and demo-monolith.

Step 1 Make Sure PostgreSQL Is Running (Windows)

PostgreSQL must be running locally on port 5432 before starting the apps:

  1. Press Win + R, type services.msc, and press Enter.
  2. Find postgresql-x64-... in the list.
  3. Check that its status is Running (if not, right-click it → Start).

Step 2 Create ems_user & demo_db in pgAdmin 4 Desktop

  1. Open the pgAdmin 4 desktop app and expand Servers → PostgreSQL (enter your PostgreSQL password).
  2. Create the user ems_user:
    • Right-click Login/Group Roles → Create → Login/Group Role...
    • In General, set Name to ems_user.
    • In Definition, set Password to ems_password.
    • In Privileges, toggle Can login? to Yes, then click Save.
  3. Create the database demo_db:
    • Right-click Databases → Create → Database...
    • Set Database to demo_db and Owner to ems_user, then click Save.
Tip: You don’t need to create any tables manually — Spring Boot will create them automatically when it starts!

Step 3 Launch demo-decoupled (SPA + REST API)

Open PowerShell or CMD inside web dev formation\demo-decoupled\ and run:

mvnw.cmd spring-boot:run

(Or open demo-decoupled in VS Code and click Run on DemoApplication.java.)

  • Frontend UI (SPA): http://localhost:8080/
  • Swagger API Docs: http://localhost:8080/swagger-ui.html

Step 4 Launch demo-monolith (Server-Rendered)

Open a second PowerShell or CMD window inside web dev formation\demo-monolith\ and run:

mvnw.cmd spring-boot:run
  • Monolith UI (Port 8081): http://localhost:8081/

Compare SPA vs. Monolith Side by Side

Open both apps in Chrome, press F12 → Network tab, and click Refresh or Add Employee:

AppURLWhat Happens in Network Tab
demo-decoupled (SPA) http://localhost:8080/ Sends lightweight JSON fetch() requests — zero page reload
demo-monolith (Thymeleaf) http://localhost:8081/ Reloads the entire HTML document on every GET / POST
