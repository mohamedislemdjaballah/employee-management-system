PostgreSQL Beginner Exercises

Hands-on SQL practice: creating tables, inserting rows, querying data, and filtering results.

How to practice: Open pgAdmin, select your database (e.g., demo_db), and open the Query Tool. Write and run your SQL queries there. Every SQL statement ends with a semicolon ;. Need a syntax refresher? Open the SQL Quick Reference or check the Solutions.
Exercise 01

Creating Tables & Inserting Data

Learn how to define tables with columns, data types, primary keys, and add rows using INSERT INTO.

CREATE TABLE PRIMARY KEY INSERT INTO
Exercise 02

Querying & Sorting Data

Read all columns or specific columns, rename outputs with aliases, sort with ORDER BY, and limit rows.

SELECT ORDER BY LIMIT DISTINCT
Exercise 03

Filtering Data with WHERE

Filter rows using comparisons, AND/OR, BETWEEN, IN, LIKE, and IS NULL.

WHERE AND / OR LIKE BETWEEN

Mini Challenge: Online Store

Put everything together in a realistic products table scenario, including filtering, sorting, and safe updates.
