Exercise 02 — Querying & Sorting Data

Use SELECT, column aliases, ORDER BY, LIMIT, and DISTINCT to read data cleanly.

Setup Sample employees Table

Run this SQL in pgAdmin if you want a fresh employees table for Exercises 02 and 03:

CREATE TABLE IF NOT EXISTS employees (
    id         SERIAL PRIMARY KEY,
    first_name TEXT NOT NULL,
    last_name  TEXT NOT NULL,
    department TEXT NOT NULL,
    salary     NUMERIC(10, 2),
    hire_year  INT,
    email      TEXT
);

Tasks Write These Queries

  1. Select everything: Display all columns and all rows from the employees table.
    Hint 
    SELECT * FROM table_name;
  2. Select specific columns: Display only first_name, last_name, and department for every employee.
    Hint 
    SELECT col1, col2, col3 FROM table_name;
  3. Use column aliases (AS): Display first_name as "First Name" and salary as annual_salary.
    Hint 
    SELECT col1 AS "Custom Name", col2 AS new_name
FROM table_name;
  4. Sort ascending: List all employees ordered by hire_year from oldest hire to newest hire (ASC).
    Hint 
    SELECT * FROM table_name ORDER BY col_name ASC;
  5. Sort descending: List all employees ordered by salary from highest to lowest (DESC).
    Hint 
    SELECT * FROM table_name ORDER BY col_name DESC;
  6. Top N rows (LIMIT): Find the top 3 highest-paid employees.
    Hint 
    SELECT * FROM table_name
ORDER BY col_name DESC
LIMIT 3;
  7. Unique values (DISTINCT): List all unique department names in the company (no duplicates).
    Hint 
    SELECT DISTINCT col_name FROM table_name;
Tip: In PostgreSQL, ORDER BY comes after FROM, and LIMIT comes at the very end of the query.
