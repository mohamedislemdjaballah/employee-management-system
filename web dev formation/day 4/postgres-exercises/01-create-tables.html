Exercise 01 — Creating Tables & Inserting Data

Practice defining table schemas with PostgreSQL data types and inserting your first rows.

Quick Reference Common PostgreSQL Data Types

Data Type Use For Example
SERIAL Auto-incrementing whole number ID id SERIAL PRIMARY KEY
INT Whole numbers (age, year, quantity) published_year INT
TEXT or VARCHAR(n) Strings / text title TEXT NOT NULL
NUMERIC(6, 2) Exact decimals like money/prices price NUMERIC(6, 2)
BOOLEAN True or false values in_stock BOOLEAN

Task 1 Create a books Table

Write a CREATE TABLE statement to create a table named books with these columns:

  • id — auto-incrementing primary key (SERIAL PRIMARY KEY)
  • title — text, cannot be empty (TEXT NOT NULL)
  • author — text, cannot be empty (TEXT NOT NULL)
  • published_year — whole number (INT)
  • price — decimal number up to 6 digits with 2 decimal places (NUMERIC(6, 2))
  • in_stock — true/false, defaults to TRUE (BOOLEAN DEFAULT TRUE)
Hint: Start with CREATE TABLE books ( ... ); and separate each column definition with a comma.
Show Query Template 
CREATE TABLE table_name (
    column1 SERIAL PRIMARY KEY,
    column2 TEXT NOT NULL,
    column3 INT,
    column4 NUMERIC(6, 2),
    column5 BOOLEAN DEFAULT TRUE
);

Task 3 Create a students Table

Create a second table named students with:

  • id — SERIAL PRIMARY KEY
  • full_name — TEXT NOT NULL
  • email — TEXT UNIQUE NOT NULL (no two students can share the same email)
  • age — INT
  • city — TEXT

Then insert at least 4 students of your choice (or make one student have NULL for city to practice missing values later).

Show Query Template 
CREATE TABLE students (
    id        SERIAL PRIMARY KEY,
    full_name TEXT NOT NULL,
    email     TEXT UNIQUE NOT NULL,
    age       INT,
    city      TEXT
);

-- Use NULL (no quotes) when a value is missing:
INSERT INTO students (full_name, email, age, city)
VALUES ('Name', 'name@example.com', 20, NULL);
