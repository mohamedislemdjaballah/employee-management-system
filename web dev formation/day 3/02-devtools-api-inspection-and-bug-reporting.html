HTTP Protocol

The 4 Core HTTP Methods (Action Verbs)

HTTP MethodAction MeaningEMS Endpoint ExampleCarries JSON Payload?
GETRead / RetrieveGET /api/employees?departmentId=1No (Filters in URL)
POSTCreate New RecordPOST /api/employeesYes (New Employee Data)
PUTUpdate / ReplacePUT /api/employees/8Yes (Updated Fields)
DELETERemove RecordDELETE /api/employees/8No (ID in URL)

REST Design Principle

In REST, the URL always names the RESOURCE (/api/employees), while the HTTP Verb dictates the ACTION (GET, POST, PUT, DELETE).

Investigation Tools

Chrome Developer Tools (F12) — Your Technical Microscope

1. Console Tab (Flight Recorder)

  • Shows bright red JavaScript errors inside Chrome.
  • Check here FIRST when a button clicks and "nothing happens" or screen freezes.
  • Capture: Exact red error text + file name & line number.

2. Network Tab (Wire Camera)

  • Records every HTTP call between Angular and Spring Boot.
  • MUST DO #1: Check "Preserve log" (keeps evidence on redirect).
  • MUST DO #2: Click "Fetch/XHR" filter (hides images & CSS).

Wire Inspection

Inspecting a Network Request (4 Essential Tabs)

1. HEADERS TAB

  • Request URL (http://localhost:8080/api/employees)
  • HTTP Method & Status Code (201 or red 409)
  • Request Headers (Authorization: Bearer...)

2. PAYLOAD TAB

  • Shows exact JSON sent by Angular
  • Only present on POST / PUT calls
  • Proves what the user actually submitted

3. RESPONSE TAB

  • Shows exact JSON returned by Spring Boot
  • Contains created ID or detailed field errors
  • Essential for diagnosing 400 / 409 / 500

4. TIMING TAB

  • Measures server response speed in ms
  • Waiting for server response (TTFB)
  • Identifies slow PostgreSQL queries

Security Concepts

Authentication (401) vs. Authorization (403) & Data Safety

Authentication vs. Authorization

  • AuthN (Who are you?): Checks password & issues JWT Token. Failure = 401 Unauthorized.
  • AuthZ (What can you do?): Checks role (ROLE_ADMIN vs ROLE_AGENT). Failure = 403 Forbidden.
  • Angular Interceptor attaches Authorization: Bearer <token> automatically.

CRITICAL SECURITY WARNING

  • NEVER share passwords in bug reports.
  • NEVER paste unredacted JWT Bearer tokens in chat or Jira.
  • MASK sensitive citizen / salary data in screenshots with [REDACTED].

Remember the Diagnostic Principle

A status code (like 400 or 500) is evidence—NOT a complete diagnosis. Always read the JSON message inside the Response tab!

Technical Communication

The Bad Report vs. The Golden Bug Report

❌ Useless Bug Report

  • "The employee screen is broken. Please fix ASAP."
  • No URL or environment.
  • No steps to reproduce.
  • No status code or error message.
  • Forces developers to guess and email back.

✅ Golden Professional Bug Report

  • 1. Title & Context: Page URL & User Role.
  • 2. Steps to Reproduce: Numbered 1, 2, 3 clicks.
  • 3. Expected vs. Actual Behavior.
  • 4. DevTools Evidence: POST /api/employees → 409 Conflict + JSON.
  • 5. Cropped, redacted screenshot attached.
