1 Classes & Objects (new)

A Class describes what an item has (fields) and can do (methods). An Object is a real item created from that class using new.

// 1. The Blueprint (Class)
public class Employee {
    public int id;
    public String name;
    public String role;
}

// 2. Creating Real Items (Objects) inside main()
Employee emp1 = new Employee();
emp1.id = 1;
emp1.name = "Alice";
emp1.role = "Developer";

Employee emp2 = new Employee();
emp2.id = 2;
emp2.name = "Bob";
emp2.role = "Designer";

2 Constructors & Methods on a Class

A Constructor fills in fields in 1 line when calling new. A Method is an action the object can perform.

public class Employee {
    public int id;
    public String name;
    public String role;

    // Constructor: runs automatically on "new"
    public Employee(int id, String name, String role) {
        this.id = id;
        this.name = name;
        this.role = role;
    }

    // Method: what the object can do
    public void sayHello() {
        System.out.println("Hi, I'm " + name + " (" + role + ")");
    }
}

// Using the constructor and method:
Employee emp1 = new Employee(1, "Alice", "Developer");
emp1.sayHello(); // prints: Hi, I'm Alice (Developer)
Tip: this.name means “this object's own field”, while name on the right is the value passed into the constructor.

3 Inheritance (extends)

Inheritance lets a child class reuse all fields and methods from a parent class using the extends keyword, so you don't repeat yourself.

// Parent class (shared fields & methods)
public class Person {
    public String name;
    public int age;

    public void introduce() {
        System.out.println("My name is " + name);
    }
}

// Child class automatically gets "name", "age", and "introduce()"
public class Employee extends Person {
    public String role;
}

// Using the child class:
Employee emp = new Employee();
emp.name = "Alice";      // inherited from Person!
emp.role = "Developer";  // defined on Employee
emp.introduce();         // inherited from Person!
Rule of thumb: Use extends when one class “is a” type of another class (an Employee is a Person).

4 Compile & Run in the Terminal (javac & java)

To run a Java file from your terminal, there are 2 simple commands:

  1. javac FileName.java — Compiles your code into a .class bytecode file (include .java).
  2. java ClassName — Runs the compiled program (do NOT add .class or .java).
# Step 1: Compile Employee.java (creates Employee.class)
javac Employee.java

# Step 2: Run the compiled class
java Employee
Common mistake: Writing java Employee.class will fail — only write the class name (java Employee)!

Practice Try It Yourself: Build a Car & ElectricCar

  • Create a Car class with public String brand;, public int speed;, a constructor, and a drive() method that prints "Toyota is driving at 80 km/h".
  • Create an ElectricCar class that extends Car and adds public int batteryPercent;.
  • In main(), create 1 Car and 1 ElectricCar and call drive() on both!
Show Solution 
public class Car {
    public String brand;
    public int speed;

    public Car() {}

    public Car(String brand, int speed) {
        this.brand = brand;
        this.speed = speed;
    }

    public void drive() {
        System.out.println(brand + " is driving at " + speed + " km/h");
    }
}

public class ElectricCar extends Car {
    public int batteryPercent;
}

// In main():
Car car1 = new Car("Toyota", 80);
car1.drive();

ElectricCar tesla = new ElectricCar();
tesla.brand = "Tesla";
tesla.speed = 110;
tesla.batteryPercent = 95;
tesla.drive(); // inherited from Car!
