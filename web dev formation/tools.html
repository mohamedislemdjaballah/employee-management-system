Workshop Tools & Setup

Everything you need installed on your machine for the 5-day Web Dev Formation.

Code Editor

VS Code & Extensions

Visual Studio Code is our main editor for HTML, CSS, JavaScript, and Java.

  • Extension Pack for Java (vscjava.vscode-java-pack) — Java syntax, Maven & debugger
  • Spring Boot Extension Pack (vmware.vscode-boot-dev-pack) — Spring Boot Dashboard & properties support
  • Live Server (ritwickdey.LiveServer) — instant preview for HTML/JS files
Backend

Java 25 (JDK 25)

Required to compile and run the Spring Boot projects (demo and Java exercises).

  • Download from Eclipse Adoptium (Temurin JDK 25)
  • Verify in terminal: java -version
  • Maven Wrapper (./mvnw) is already included in the project
Database

PostgreSQL & pgAdmin 4

Our relational database server (port 5432) and desktop management UI.

  • PostgreSQL — database engine
  • pgAdmin 4 Desktop — create databases, inspect tables & run SQL queries
API & Debugging

Browser DevTools & Postman

Essential for inspecting HTTP requests, JSON payloads, and JavaScript console logs.

  • Chrome / Edge DevTools (F12) — Console & Network tabs
  • Postman — test GET, POST, PUT, DELETE endpoints
