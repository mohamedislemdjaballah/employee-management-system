Solution 01 — Creating Tables & Inserting Data

SQL solutions for creating books and students and inserting sample rows.

Task 1 Create the books Table

CREATE TABLE books (
    id             SERIAL PRIMARY KEY,
    title          TEXT NOT NULL,
    author         TEXT NOT NULL,
    published_year INT,
    price          NUMERIC(6, 2),
    in_stock       BOOLEAN DEFAULT TRUE
);
SERIAL PRIMARY KEY automatically generates 1, 2, 3… for each new row.
