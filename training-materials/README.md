# Training Materials Suite: Day 3 Practical Workshop
## "Working with Modern Web Applications: Angular Frontend & Spring Boot Backend"

**Audience:** Senior Enterprise Engineers (Ages 30–40, Ministry of Finance / SIT)  
**Instructor:** Backend Developer (Laravel / PHP background)  
**Format:** 6-Hour Practical Workshop (08:00–12:00 and 13:00–15:00)  
**Methodology:** 20% Theory, 20% Demonstration, 60% Hands-On. Zero programming required.

## 🚀 Quick Instructor Launch

1. To launch the entire application suite on your laptop before class:
   ```cmd
   start-all.bat
   ```
2. Open **Google Chrome** to:
   - Application: `http://localhost:4200`
   - Swagger REST API: `http://localhost:8080/swagger-ui.html`
3. Open `01-instructor-guide.md` and begin Session 1 at 08:00!
