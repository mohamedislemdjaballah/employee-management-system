Exercise 03 — Filtering Data with WHERE

Use the employees table from Exercise 02 to practice filtering rows with precision.

Cheat Sheet Filter Operators

OperatorMeaningExample
=, != (or <>)Equal / Not equaldepartment = 'Sales'
>, <, >=, <=Greater / Less thansalary >= 70000
AND, OR, NOTCombine conditionsdepartment = 'Sales' AND salary > 60000
BETWEEN a AND bInclusive rangehire_year BETWEEN 2020 AND 2022
IN (...)Match any item in a listdepartment IN ('HR', 'Sales')
LIKE / ILIKEPattern match (% = any chars)first_name ILIKE 'a%'
IS NULL / IS NOT NULLCheck for missing valuesemail IS NULL

Part A Basic Comparisons

  1. Find all employees who work in the 'Engineering' department.
    Hint 
    SELECT * FROM employees WHERE col_name = 'Value';
  2. Find all employees whose salary is strictly greater than 70000.
    Hint 
    SELECT * FROM employees WHERE num_col > 70000;
  3. Find all employees who do not work in 'Marketing'.
    Hint 
    SELECT * FROM employees WHERE col_name != 'Value';

Part B Combining Conditions & Ranges

  1. Find employees in 'Engineering' who earn at least 80000 (AND).
    Hint 
    SELECT * FROM employees WHERE col1 = 'Val' AND col2 >= 80000;
  2. Find employees who are either in 'HR' or in 'Sales' (try using OR, or rewrite it with IN).
    Hint 
    SELECT * FROM employees WHERE col1 IN ('Val1', 'Val2');
  3. Find employees hired between 2020 and 2022 (inclusive) using BETWEEN.
    Hint 
    SELECT * FROM employees WHERE col_name BETWEEN 2020 AND 2022;
  4. Find employees whose salary is between 55000 and 65000, sorted by salary descending.
    Hint 
    SELECT * FROM employees
WHERE num_col BETWEEN 55000 AND 65000
ORDER BY num_col DESC;

Part C Patterns & NULL Values

  1. Find all employees whose first_name starts with the letter 'A' or 'a' (hint: ILIKE 'a%' is case-insensitive in PostgreSQL).
    Hint 
    SELECT * FROM employees WHERE first_name ILIKE 'a%';
  2. Find all employees whose last_name contains the letter 'o' anywhere (hint: '%o%').
    Hint 
    SELECT * FROM employees WHERE last_name ILIKE '%o%';
  3. Find all employees who do not have an email address recorded (email IS NULL).
    Hint 
    SELECT * FROM employees WHERE email IS NULL;
  4. Find all employees who do have an email address and work in 'Engineering'.
    Hint 
    SELECT * FROM employees WHERE email IS NOT NULL AND department = '...';
Watch out: Never write email = NULL! In SQL, NULL means “unknown”, so you must always use IS NULL or IS NOT NULL.
