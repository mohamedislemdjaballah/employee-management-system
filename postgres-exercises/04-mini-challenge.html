Exercise 04 — Mini Challenge: Online Store

Combine CREATE TABLE, INSERT, SELECT, WHERE, ORDER BY, and safe UPDATE/DELETE.

Step 1 Create the products Table

Create a table named products with these columns:

  • id — SERIAL PRIMARY KEY
  • name — TEXT NOT NULL
  • category — TEXT NOT NULL
  • price — NUMERIC(8, 2) NOT NULL
  • stock — INT DEFAULT 0
Hint 
CREATE TABLE products (
    id       SERIAL PRIMARY KEY,
    name     TEXT NOT NULL,
    category TEXT NOT NULL,
    price    NUMERIC(8, 2) NOT NULL,
    stock    INT DEFAULT 0
);

Step 3 Query & Filter the Store

  1. Show all 'Electronics' products that are currently in stock (stock > 0).
    Hint 
    SELECT * FROM products WHERE category = '...' AND stock > 0;
  2. Show all products that are out of stock (stock = 0).
    Hint 
    SELECT * FROM products WHERE stock = 0;
  3. Show the 2 cheapest products in the store (ORDER BY price ASC LIMIT 2).
    Hint 
    SELECT * FROM products ORDER BY price ASC LIMIT 2;
  4. Show all products whose name contains 'Desk' (case-insensitive) and cost less than 100.
    Hint 
    SELECT * FROM products WHERE name ILIKE '%...%' AND price < 100;

Step 4 Bonus: Safe UPDATE & DELETE

  1. Restock the 'Coffee Mug' by setting its stock to 25 using UPDATE ... WHERE.
    Hint 
    UPDATE products SET stock = 25 WHERE name = '...';
  2. Delete the 'Desk Lamp' product from the table using DELETE FROM ... WHERE.
    Hint 
    DELETE FROM products WHERE name = '...';
Always check your WHERE clause! Without WHERE, UPDATE or DELETE affects every single row in the table.
