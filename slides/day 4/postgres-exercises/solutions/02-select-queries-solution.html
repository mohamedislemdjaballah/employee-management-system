Solution 02 — Querying & Sorting Data

Solutions for SELECT, aliases, ORDER BY, LIMIT, and DISTINCT.

1. Select everything

SELECT * FROM employees;

2. Select specific columns

SELECT first_name, last_name, department
FROM employees;

3. Use column aliases (AS)

SELECT first_name AS "First Name",
       salary     AS annual_salary
FROM employees;

4. Sort ascending by hire_year

SELECT *
FROM employees
ORDER BY hire_year ASC;

5. Sort descending by salary

SELECT *
FROM employees
ORDER BY salary DESC;

6. Top 3 highest-paid employees

SELECT *
FROM employees
ORDER BY salary DESC
LIMIT 3;

7. Unique department names

SELECT DISTINCT department
FROM employees;
