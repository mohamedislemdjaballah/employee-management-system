Part 1 of 2 • Database Setup First

1. Open pgAdmin Desktop & Create demo_db

Connect your installed pgAdmin 4 desktop app to your local PostgreSQL server and create an empty demo_db database.

Step 1 Open pgAdmin 4 Desktop

  1. Launch the pgAdmin 4 desktop app on your computer.
  2. In the left sidebar, expand Servers and click your local PostgreSQL server (enter your PostgreSQL password if asked).
Server not listed yet? Right-click Servers → Register → Server..., name it Local Postgres, and in the Connection tab enter:
FieldValue
Host name/addresslocalhost
Port5432
Maintenance databasepostgres
Usernamepostgres
Password(your PostgreSQL password)

Step 2 Create the demo_db Database

  1. Expand your PostgreSQL server in the left sidebar.
  2. Right-click on Databases → hover over Create → click Database...
  3. In the popup window:
    • Database: type demo_db (exact spelling, lowercase, with an underscore _)
    • Owner: leave as postgres (or select ems_user if created)
  4. Click Save.
Tip: Don’t create any tables manually! Once you start Spring Boot with ddl-auto=update, Spring will create the department, employee, and task tables inside demo_db automatically.

Step 3 Verify Your Database & Tables

In the left sidebar, you should now see demo_db under Databases:

Servers
└── PostgreSQL
    └── Databases
        ├── demo_db
        │   └── Schemas → public → Tables (empty until Spring Boot runs!)
        └── postgres

After you run Spring Boot, right-click Tables → Refresh... to see your new tables appear, and right-click any table → View/Edit Data → All Rows to see saved rows.
