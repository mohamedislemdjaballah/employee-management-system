Part 1 of 2 • Database Setup First

1. Start Postgres & Create demo_db in pgAdmin

Launch PostgreSQL and pgAdmin with Docker Compose, then create an empty demo_db database.

Step 1 Start PostgreSQL & pgAdmin via Docker Compose

Open a terminal in the project root folder (where docker-compose.yml is located) and run:

docker compose up -d postgres pgadmin
Why only postgres pgadmin? This starts PostgreSQL (port 5432) and pgAdmin (port 5050), while keeping port 8080 free for your demo Spring Boot app!

Step 2 Open pgAdmin & Log In

  1. Open pgAdmin in your browser: http://localhost:5050
  2. Log in with the credentials from docker-compose.yml:
    FieldValue
    Email Address / Usernameadmin@finances.gov
    Passwordadmin

Step 3 Connect pgAdmin to the PostgreSQL Server

  1. In the left sidebar, right-click Servers → hover over Register → click Server...
  2. In the General tab, set Name to EMS Postgres.
  3. Click the Connection tab and enter:
    FieldValue
    Host name/addresspostgres
    Port5432
    Maintenance databaseems_db
    Usernameems_user
    Passwordems_password
  4. Check Save password? and click Save.
Important: Use postgres as the Host name (not localhost), because pgAdmin is running inside a Docker container and connects to the postgres service name.

Step 4 Create the demo_db Database

  1. Expand EMS Postgres in the left sidebar.
  2. Right-click on Databases → hover over Create → click Database...
  3. In the popup window:
    • Database: type demo_db (exact spelling, lowercase, with an underscore _)
    • Owner: leave as ems_user
  4. Click Save.
Tip: Don't create any tables manually! Once you start Spring Boot with ddl-auto=update, Spring will create the department, employee, and task tables inside demo_db automatically.

Step 5 Verify Your Database & Tables

In the left sidebar, you should now see demo_db under Databases:

Servers
└── EMS Postgres
    └── Databases
        ├── demo_db
        │   └── Schemas → public → Tables (empty until Spring Boot runs!)
        └── ems_db

After you run Spring Boot, right-click Tables → Refresh... to see your new tables appear, and right-click any table → View/Edit Data → All Rows to see saved rows.
