Part 2

Including JavaScript in HTML

Two ways to add JavaScript to a web page: directly inside HTML or via an external .js file.

Part 2 • JS in HTML

Way 1: Writing JavaScript Directly in HTML

Put a <script> tag right before the closing </body> tag.

<!DOCTYPE html>
<html>
<head>
  <title>My App</title>
</head>
<body>
  <button id="btn">Click me</button>

  <!-- JavaScript placed right before </body> -->
  <script>
    const btn = document.getElementById('btn');

    function handleClick() {
      alert('Button clicked!');
    }

    btn.addEventListener('click', handleClick);
  </script>
</body>
</html>

Why at the bottom of <body>? So the browser finishes loading the HTML elements (like #btn) before JavaScript tries to find them.

Part 2 • JS in HTML

Way 2: Linking an External .js File (Best Practice)

Keep HTML and JavaScript in separate files using <script src="..." defer>.

index.html

<!DOCTYPE html>
<html>
<head>
  <title>My App</title>
  <!-- defer waits for HTML to load -->
  <script src="app.js" defer></script>
</head>
<body>
  <button id="btn">Click me</button>
</body>
</html>

app.js

// Runs after HTML is ready!
const btn = document.getElementById('btn');

function handleClick() {
  alert('Button clicked!');
}

btn.addEventListener('click', handleClick);

Why external + defer? Cleaner code, reusable across pages, and defer guarantees HTML loads before JS runs.

Part 3

JavaScript Syntax & Code Examples

Variables, conditionals, loops, functions, objects, and interacting with the page.

Part 3 • Basic Syntax

1. Variables & Data Types (const & let)

Store values in named containers — use const by default, let if it changes.

const companyName = 'Acme Corp';   // String (cannot be reassigned)
let employeeCount = 42;            // Number (can be changed later)
employeeCount = 43;

const isActive = true;             // Boolean (true or false)
const skills = ['Java', 'SQL'];    // Array (list of items)
const user = { name: 'Alice', age: 28 }; // Object (key-value pairs)

console.log(companyName, employeeCount); // Prints to DevTools Console

Tip: In modern JavaScript, avoid the old var keyword — always use const or let.

Part 3 • Basic Syntax

2. Conditionals (if / else)

Make decisions in code; always use === (strict equality) instead of ==.

const role = 'Admin';
const age = 22;

if (role === 'Admin' && age >= 18) {
  console.log('Full access granted');
} else if (role === 'Guest') {
  console.log('Read-only access');
} else {
  console.log('Access denied');
}

Why ===? 5 === '5' is false (checks value AND type), preventing tricky bugs.

Part 3 • Basic Syntax

3. Loops (for & for...of)

Repeat an action multiple times or go through every item in a list.

Classic for loop

for (let i = 1; i <= 3; i++) {
  console.log('Step ' + i);
}
// Step 1, Step 2, Step 3

Looping an Array (for...of)

const names = ['Alice', 'Bob', 'Sara'];

for (const name of names) {
  console.log('Hello, ' + name + '!');
}

String Concatenation: Use + to join text and variables together (e.g. 'Hello, ' + name + '!').

Part 3 • Basic Syntax

4. Functions

Reusable blocks of logic that take inputs (parameters) and return an output.

Function with 1 Parameter

function greet(name) {
  return 'Welcome, ' + name + '!';
}

console.log(greet('Alice'));
// "Welcome, Alice!"

Function with 2 Parameters

function add(a, b) {
  return a + b;
}

console.log(add(5, 3));
// 8

5. Working with Arrays & Objects

Most REST APIs return an array of JSON objects — here is how JS handles them.

const employees = [
  { id: 1, name: 'Alice', role: 'Developer' },

Part 3 • Basic Syntax

6. Selecting Elements (id & class)

Before changing an element or listening for clicks, JavaScript needs to find it in the HTML.

HTML

<h1 id="main-title">Welcome</h1>

<p class="note">First note</p>
<p class="note">Second note</p>

JavaScript

// Select 1 element by id
const title = document.getElementById('main-title');

// Select ALL elements by class
const notes = document.getElementsByClassName('note');
const firstNote = notes[0];

Remember: With getElementById and getElementsByClassName, pass the name directly — no # or . needed!

Part 3 • Basic Syntax

7. Interacting with the Page (DOM & Events)

Find an HTML element, listen for a click, and update the screen without reloading.

HTML

<p id="count">Clicked 0 times</p>
<button id="addBtn">Add 1</button>

CSS

#count { font-weight: bold; }
#addBtn {
  background: #2563eb;
  color: white;
  padding: 8px 16px;
  border-radius: 8px;
}

Working Example

Clicked 0 times

JavaScript

// 1. Find HTML elements
const countText = document.getElementById('count');
const addBtn    = document.getElementById('addBtn');

let count = 0;

// 2. Define a handler function
function incrementCount() {
  count = count + 1;
  countText.textContent = 'Clicked ' + count + ' times';
}

// 3. Pass it by name as a callback
addBtn.addEventListener('click', incrementCount);

8. Adding Rows to an Empty Table

Append new HTML rows directly into a table’s <tbody> using innerHTML.

HTML

<h3>Employees</h3>
<table>
  <thead><tr><th>ID</th><th>Name</th></tr></thead>
  <tbody id="employeeTable"></tbody>
</table>
<button id="addRowBtn">Add Employee</button>

JavaScript

const tbody = document.getElementById('employeeTable');
const btn   = document.getElementById('addRowBtn');
let nextId  = 1;

function addEmployeeRow() {
  tbody.innerHTML = tbody.innerHTML +
    '<tr><td>' + nextId + '</td><td>Alice</td></tr>';
  nextId = nextId + 1;
}

btn.addEventListener('click', addEmployeeRow);
