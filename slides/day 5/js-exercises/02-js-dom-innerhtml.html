Série 02 — Sélectionner des Éléments & innerHTML

3 exercices pour pratiquer getElementById(), getElementsByClassName(), les événements et innerHTML.

Préparation Comment tester votre code

  1. Créez un fichier nommé dom-test.html sur votre ordinateur.
  2. Placez le HTML de l’exercice dans <body> et votre fonction JavaScript dans <script> juste avant </body>, puis appelez-la juste après.
  3. Double-cliquez sur dom-test.html pour voir la page se mettre à jour dans votre navigateur (et ouvrez F12 → Console si besoin).
<!DOCTYPE html>
<html>
<body>
  <h1 id="demo">Bonjour</h1>

  <script>
    // 1. Définissez votre fonction
    function changeDemo() {
      const el = document.getElementById('demo');
      el.innerHTML = 'Modifié par JS !';
    }

    // 2. Appelez la fonction juste après sa définition
    changeDemo();
  </script>
</body>
</html>

Exercice 1 Modifier le Titre et un Paragraphe

Sélectionnez le titre par son id (#title) et le paragraphe par sa class (.info), puis modifiez leur innerHTML.

HTML initial :

<h1 id="title">Bienvenue</h1>
<p class="info">Texte initial</p>

Résultat HTML attendu :

<h1 id="title">Bonjour <strong>JavaScript</strong> !</h1>
<p class="info">Page chargée avec succès.</p>
Aperçu initial

Bienvenue

Texte initial

Aperçu attendu

Bonjour JavaScript !

Page chargée avec succès.

Exemple 1 :
Entrée : #title contient Bienvenue
Sortie : #title affiche Bonjour <strong>JavaScript</strong> !

Exemple 2 :
Entrée : .info contient Texte initial
Sortie : .info affiche Page chargée avec succès.
Voir la Solution 
function updatePage() {
  const title = document.getElementById('title');
  const infos = document.getElementsByClassName('info');

  title.innerHTML    = 'Bonjour <strong>JavaScript</strong> !';
  infos[0].innerHTML = 'Page chargée avec succès.';
}

updatePage();

Exercice 2 Compteur de Clics avec innerHTML

Définissez une fonction nommée handleClick() et passez-la par son nom à addEventListener('click', handleClick) pour compter les clics dans #message.

HTML initial :

<p id="message">Clics : 0</p>
<button id="clickBtn">Cliquer</button>

Résultat HTML attendu (après 1 clic) :

<p id="message">Clics : <strong>1</strong></p>
<button id="clickBtn">Cliquer</button>
Aperçu initial

Clics : 0

Aperçu attendu (après 1 clic)

Clics : 1

Exemple 1 :
Entrée : 1er clic sur le bouton #clickBtn
Sortie : #message affiche Clics : <strong>1</strong>

Exemple 2 :
Entrée : 3ème clic sur le bouton #clickBtn
Sortie : #message affiche Clics : <strong>3</strong>
Voir la Solution 
function setupCounter() {
  const msg = document.getElementById('message');
  const btn = document.getElementById('clickBtn');
  let count = 0;

  function handleClick() {
    count = count + 1;
    msg.innerHTML = 'Clics : <strong>' + count + '</strong>';
  }

  btn.addEventListener('click', handleClick);
}

setupCounter();

Exercice 3 Ajouter des Lignes à un Tableau Vide

Sélectionnez le <tbody id="studentTable"> et ajoutez une nouvelle ligne <tr><td>...</td><td>...</td></tr> avec innerHTML à chaque clic sur #addBtn.

HTML initial :

<h3>Étudiants</h3>
<table>
  <thead><tr><th>ID</th><th>Nom</th></tr></thead>
  <tbody id="studentTable"></tbody>
</table>
<button id="addBtn">Ajouter Étudiant</button>

Résultat HTML attendu (après 2 clics) :

<h3>Étudiants</h3>
<table>
  <thead><tr><th>ID</th><th>Nom</th></tr></thead>
  <tbody id="studentTable">
    <tr><td>1</td><td>Sara</td></tr>
    <tr><td>2</td><td>Sara</td></tr>
  </tbody>
</table>
<button id="addBtn">Ajouter Étudiant</button>

Étudiants

IDNom

Exemple 1 :
Entrée : 1er clic sur #addBtn
Sortie : Le tableau contient 1 | Sara

Exemple 2 :
Entrée : 2ème clic sur #addBtn
Sortie : Le tableau contient 1 | Sara et 2 | Sara
Voir la Solution 
function setupStudentTable() {
  const tbody = document.getElementById('studentTable');
  const btn   = document.getElementById('addBtn');
  let nextId  = 1;

  function addStudent() {
    tbody.innerHTML = tbody.innerHTML +
      '<tr><td>' + nextId + '</td><td>Sara</td></tr>';
    nextId = nextId + 1;
  }

  btn.addEventListener('click', addStudent);
}

setupStudentTable();
