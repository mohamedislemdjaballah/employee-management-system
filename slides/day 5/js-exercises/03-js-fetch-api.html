Série 03 — Appeler une API REST avec fetch()

3 exercices pour pratiquer les requêtes GET, POST et DELETE sur une API publique.

Préparation Comment tester votre code avec fetch()

  1. Créez un fichier nommé fetch-test.html sur votre ordinateur.
  2. Utilisez une fonction async function avec await fetch(...) dans <script>, puis appelez la fonction juste après.
  3. Double-cliquez sur fetch-test.html, appuyez sur F12 et vérifiez les onglets Console et Network (Réseau).
<!DOCTYPE html>
<html>
<body>
  <h1>Ouvrez la Console (F12)</h1>

  <script>
    // 1. Définissez une fonction async
    async function getExample() {
      const response = await fetch('https://jsonplaceholder.typicode.com/posts/1');
      const data = await response.json();
      console.log(data);
    }

    // 2. Appelez la fonction juste après
    getExample();
  </script>
</body>
</html>

Exercice 1 Lire un Utilisateur (GET)

Écrivez une fonction getUser(id) qui envoie une requête GET vers l’API publique JSONPlaceholder et affiche le nom de l’utilisateur dans la console :

  • URL : https://jsonplaceholder.typicode.com/users/ + id
  • Méthode : GET
Exemple 1 :
Entrée : getUser(1) → GET https://jsonplaceholder.typicode.com/users/1
Sortie : Nom : Leanne Graham

Exemple 2 :
Entrée : getUser(2) → GET https://jsonplaceholder.typicode.com/users/2
Sortie : Nom : Ervin Howell
Voir la Solution 
async function getUser(id) {
  const response = await fetch('https://jsonplaceholder.typicode.com/users/' + id, {
    method: 'GET'
  });
  const user = await response.json();
  console.log('Nom : ' + user.name);
}

getUser(1);
getUser(2);

Exercice 2 Créer un Post (POST)

Écrivez une fonction createPost(title, bodyText) qui envoie un nouvel article en JSON vers l’API :

  • URL : https://jsonplaceholder.typicode.com/posts
  • Méthode : POST
  • Headers : { 'Content-Type': 'application/json' }
  • Body (JSON) : { title: title, body: bodyText, userId: 1 }
Exemple 1 :
Entrée : createPost('Mon Post', 'Bonjour API')
Sortie : Statut : 201 et { id: 101, title: 'Mon Post', body: 'Bonjour API', userId: 1 }

Exemple 2 :
Entrée : createPost('Test JS', 'Fetch fonctionne')
Sortie : Statut : 201 et { id: 101, title: 'Test JS', body: 'Fetch fonctionne', userId: 1 }
Voir la Solution 
async function createPost(title, bodyText) {
  const response = await fetch('https://jsonplaceholder.typicode.com/posts', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      title: title,
      body: bodyText,
      userId: 1
    })
  });

  const created = await response.json();
  console.log('Statut : ' + response.status);
  console.log(created);
}

createPost('Mon Post', 'Bonjour API');

Exercice 3 Supprimer un Post (DELETE)

Écrivez une fonction deletePost(id) qui envoie une requête DELETE pour supprimer un article et affiche le code de statut HTTP dans la console :

  • URL : https://jsonplaceholder.typicode.com/posts/ + id
  • Méthode : DELETE
Exemple 1 :
Entrée : deletePost(1) → DELETE https://jsonplaceholder.typicode.com/posts/1
Sortie : Post 1 supprimé, statut : 200

Exemple 2 :
Entrée : deletePost(5) → DELETE https://jsonplaceholder.typicode.com/posts/5
Sortie : Post 5 supprimé, statut : 200
Voir la Solution 
async function deletePost(id) {
  const response = await fetch('https://jsonplaceholder.typicode.com/posts/' + id, {
    method: 'DELETE'
  });
  console.log('Post ' + id + ' supprimé, statut : ' + response.status);
}

deletePost(1);
deletePost(5);
