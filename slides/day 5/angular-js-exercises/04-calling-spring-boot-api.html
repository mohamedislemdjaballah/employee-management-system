Exercise 04 (Mini-Challenge): Calling Spring Boot with Plain fetch()

Make sure Spring Boot is running on http://localhost:8080 (or check the Network tab with F12!):

  1. Inside loadFromSpringBoot(), call fetch("http://localhost:8080/api/employees").
  2. Convert the HTTP response with .then(res => res.json()).
  3. Loop through the returned array and render the rows inside #api-table-body!
