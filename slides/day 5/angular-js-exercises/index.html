DAY 5 • PLAIN JAVASCRIPT EXERCISES (NO TYPESCRIPT)

Understanding How Angular Works Under the Hood

Build 4 small interactive widgets using standard HTML & plain JavaScript—the exact code Angular generates automatically when compiled!

How to do these exercises:
1. Open the exercise file in VS Code to read the // TODO: comments inside the <script> tag.
2. Open the same file in Google Chrome (double-click it) and press F12 → Console to see output or errors.
3. Edit the JavaScript in VS Code, save (Ctrl + S), and refresh Chrome (F5)!
