Exercise 03: Client-Side Validation & preventDefault()

Open this file in VS Code and complete the form validation inside <script>:

  1. Call event.preventDefault() inside the submit listener so Chrome does not reload the page.
  2. Check if fullName.trim() === "". If empty, add class "invalid" to the input and show #name-error.
  3. Check if !email.includes("@"). If invalid, show #email-error.
  4. Check if Number(salary) <= 0. If invalid, show #salary-error.
  5. If all 3 checks pass, display #success-box!
Full name is required.
Email must contain an @ symbol.
Salary must be greater than 0.
