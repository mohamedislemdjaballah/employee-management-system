Plain JavaScript Quick Reference

Everything you need to complete today's 4 exercises—with Angular equivalents.

1. Variables & Objects (No TypeScript types needed)

Use const for values that don't get reassigned, and let for values that change.

const employee = {
  firstName: "Karim",
  lastName: "BENALI",
  salary: 145000,
  status: "ACTIVE"
};

2. Updating Text on Screen (What Angular {{ }} compiles to)

Find an HTML tag by its id="..." and set its textContent.

const nameBox = document.getElementById("emp-name");
nameBox.textContent = employee.firstName + " " + employee.lastName;

3. Listening for Clicks (What Angular (click) compiles to)

const btn = document.getElementById("raise-btn");
btn.addEventListener("click", function() {
  employee.salary = employee.salary + 10000;
});

4. Looping & Filtering Arrays (What Angular @for compiles to)

const tbody = document.getElementById("table-body");
tbody.innerHTML = ""; // Clear existing rows first

employees.forEach(function(emp) {
  const row = document.createElement("tr");
  row.innerHTML = `<td>${emp.firstName}</td><td>${emp.salary} DA</td>`;
  tbody.appendChild(row);
});

// Filtering an array:
const sitOnly = employees.filter(function(emp) {
  return emp.departmentCode === "SIT";
});

5. Calling a REST API (What Angular HttpClient compiles to)

fetch("http://localhost:8080/api/employees")
  .then(function(response) {
    return response.json(); // Convert JSON text to JS Array
  })
  .then(function(data) {
    console.log("Employees loaded:", data);
  });
