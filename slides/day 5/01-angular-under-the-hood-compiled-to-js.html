The Big Truth

Chrome Only Understands 3 Languages

1. HTML

Structure of the page (tables, buttons, inputs).

2. CSS

Colors, spacing, fonts, and badges.

3. JavaScript

Clicks, loops, conditions, and fetch() calls.

What Happens When You Run ng build / npm start?

Angular Source (.ts + .html)  →  Angular Compiler  →  Plain JavaScript (main.js)

Chrome NEVER runs TypeScript or @Component! Everything you see in the browser is compiled into plain JavaScript.

Compilation Step 1

Stripping TypeScript Into Plain JavaScript

What Happens During Compilation?

  • Developers write type labels (like : string or interface) to catch typos early.
  • When compiled for the browser, 100% of those type labels are deleted!
  • What actually runs in Google Chrome is ordinary JavaScript objects and functions.

Compilation Step 2

What Is an Angular Component in Plain JavaScript?

Plain-English Mental Model

  • Think of a Component as a self-contained JavaScript object managing one box on screen.
  • Properties: Data remembered by that box (e.g., this.salary).
  • Methods: Actions triggered by buttons (e.g., giveRaise()).

COMPILED PLAIN JAVASCRIPT CLASS

class EmployeeCard {
  constructor() {
    this.fullName = "Karim BENALI";
    this.salary = 145000;
    this.status = "ACTIVE";
  }

  giveRaise(amount) {
    this.salary = this.salary + amount;
    this.render(); // Redraws the HTML
  }
}

How @if Conditionals Compile to JavaScript

@if (emp.status === 'ACTIVE') {
  <span class="badge-green">En Activité</span>

COMPILED PLAIN JAVASCRIPT

function renderStatusBadge(status) {
  const badge = document.createElement("span");

  if (status === "ACTIVE") {
    badge.className = "badge-green";
    badge.textContent = "En Activité";
  } else {
    badge.className = "badge-yellow";
    badge.textContent = "En Congé";
  }
  return badge;
}

Loops → JavaScript

How @for Loops Compile to JavaScript

ANGULAR HTML TEMPLATE

<tbody>
  @for (emp of employees; track emp.id) {
    <tr>
      <td>{{ emp.firstName }} {{ emp.lastName }}</td>
      <td>{{ emp.salary }} DA</td>
    </tr>
  }
</tbody>

COMPILED PLAIN JAVASCRIPT

function renderTable(employees) {
  const tbody = document.getElementById("table-body");
  tbody.innerHTML = ""; // Clear old rows

  employees.forEach(function(emp) {
    const row = document.createElement("tr");
    row.innerHTML = `
      <td>${emp.firstName} ${emp.lastName}</td>
      <td>${emp.salary} DA</td>
    `;
    tbody.appendChild(row);
  });
}

Architecture → JavaScript

What Is an Angular Service in Plain JavaScript?

The Concept (Singleton Helper)

  • In Angular, a Service holds shared business functions and API calls.
  • In compiled JavaScript, it is simply one shared object created once in browser memory!
  • Multiple screens reuse the exact same functions (e.g., filtering or fetching).

COMPILED PLAIN JAVASCRIPT SERVICE

const employeeService = {
  apiUrl: "http://localhost:8080/api/employees",

  filterByDepartment: function(employees, deptCode) {
    if (!deptCode) return employees;
    return employees.filter(function(emp) {
      return emp.departmentCode === deptCode;
    });
  }
};

Network → JavaScript

How Angular Calls Spring Boot Using Plain fetch()

Why .then() Is Required

  • Chrome's fetch() sends an HTTP request to Spring Boot on port 8080.
  • Because the network takes 10–100 ms, Chrome does not freeze the screen.
  • When JSON arrives back, .then() runs automatically and updates the table!

PLAIN JAVASCRIPT FETCH API

function loadEmployeesFromServer() {
  fetch("http://localhost:8080/api/employees")
    .then(function(response) {
      return response.json(); // Read JSON text
    })
    .then(function(employees) {
      renderTable(employees); // Draw rows!
    })
    .catch(function(err) {
      console.error("Server unreachable:", err);
    });
}

Forms → JavaScript

How Form Validation & POST Compile to JavaScript

PLAIN JAVASCRIPT FORM SUBMIT & POST REQUEST

form.addEventListener("submit", function(event) {
  event.preventDefault(); // 1. Stop browser from reloading the page!

  const email = document.getElementById("email").value;
  if (!email.includes("@")) {
    alert("Invalid email format!"); // 2. Client-side validation check
    return;
  }

  const newEmployee = { firstName: "Karim", email: email, salary: 120000 };

  fetch("http://localhost:8080/api/employees", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(newEmployee) // 3. Convert JS object to JSON text
  }).then(res => console.log("Saved! Status:", res.status));
});

Big Picture

Why Use Angular Instead of Writing Raw JS Manually?

Writing Raw JavaScript Manually

  • Dozens of document.getElementById() calls on every screen.
  • Easy to forget tbody.innerHTML = "" or preventDefault().
  • Becomes messy and fragile when an enterprise portal grows to 50+ screens.

Using Angular

  • Developers write clean HTML templates (@for, @if, {{ emp.name }}).
  • Angular's compiler automatically generates all the tedious DOM JavaScript!
  • Your Insight: Now you understand BOTH the Angular view and the JS underneath.
